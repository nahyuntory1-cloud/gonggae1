원인행위 결의 내역과 법인카드 매출 내역을 금액 기준으로 자동 대사(對査)하여, 분기별 업무추진비 공개표를 만듭니다.

「원인행위목록」의 결의 건을 기준행으로 삼아 집행내역(제목)을 항상 채우고, 금액이 일치하는 「카드승인내역(에듀파인)」 승인 건이 있으면 그 건의 실제 승인일시·가맹점을 가져와 집행일자·시간·장소를 채웁니다. 짝을 찾지 못한 건은 직접 선택해 매칭할 수 있습니다.

2

자료 업로드

두 엑셀 파일을 각각 업로드하세요. 클릭하거나 파일을 끌어다 놓을 수 있습니다.

① 원인행위목록 (에듀파인)
결의 건별 원인행위금액 · 제목 · 유형이 담긴 파일
다운로드 경로 에듀파인 로그인 → 학교회계 → 지출관리 → 원인행위목록 → 목(업무추진비) 지정 → 조회 후 엑셀 다운로드
② 카드승인내역 (에듀파인)
법인카드 승인 건별 승인일시 · 승인금액 · 가맹점명이 담긴 파일
다운로드 경로 에듀파인 로그인 → 학교회계 → 지출관리 → 기타관리 → 카드승인내역 → 조회 후 엑셀 다운로드
지금 표시된 내용은 예시(가상) 데이터입니다. 실제 파일을 업로드하면 자동으로 예시 데이터가 지워집니다.
3

매칭 결과 검수

원인행위 결의 건마다 한 행이 만들어지며, 금액이 정확히 일치하는 카드 승인 건이 있으면 집행일자·시간·장소가 자동으로 채워집니다. 셀을 클릭해 내용을 고치거나, 미매칭 건은 목록에서 직접 카드 승인 건을 선택하세요.

업로드하신 매출내역 파일에는 승인시각 항목 자체가 없어 집행시간 칸이 비어 있는 것이 정상입니다 (일자·금액·가맹점명은 정상 반영). 시간이 필요하면 승인시각이 있는 카드사 파일을 사용하시거나, 표의 집행시간 칸을 클릭해 직접 입력하세요.
날짜순 정렬 · 제외된 건은 취소선으로 표시되며 집계·내보내기에서 빠집니다
